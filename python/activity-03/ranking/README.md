# Player Ranking

A simple Python console application that manages a ranking of players, allowing insertion, removal, counting, and sorting of names.

## Description

The program provides a menu with options to:

- Add a player to the end of the ranking
- Insert a player at a specific position
- Remove a player by position
- Count how many times a name appears in the ranking
- Display the ranking in alphabetical order

The ranking has a maximum limit of 10 players.

## Features

- Dynamic list management
- Input validation for numeric values
- Name formatting using capitalization
- Sorting functionality
