# List of Exercicies

A simple C# application that provides eight exercicies:
1. **Classificador de idade** – age classifier to determine whether the user is a child, a teenager, an adult, or a senior.
2. **Conversor de temperatura** - temperature converter, which converts Fahrenheit to Celsius.
3. **Situação do aluno** - calculates the average of three grades and determines whether the student is approved, needs an exam, or has failed.
4. **Tabuada com laço** - multiplication table for a number entered by the user
5. **Estatísticas de uma lista de notas** - calculates the highest grade, lowest grade, sum, and average of a list of grades and displays the results.   
6. **Filtrar números pares** - filters a list of numbers into separate lists of even and odd numbers.
7. **Maior e menor venda da semana** - a dictionary of daily sales that shows the days with the highest and lowest sales.
8. **Gerenciador de tarefas** - a task management application that can add, remove, check, and display tasks from a list.

# Description

The program:

- Display a menu with nine options, eight exercicies and one option to end the program:
  - **Exercise 1: Classificador de idade**
    - Read the age entered by the user. 
    - Classify the user according to the entered age.
  - **Exercise 2: Conversor de temperatura**
    - Read the temperature entered by the user in Fahrenheit.
    - Convert the temperature from Fahrenheit to Celsius.
    - Display the converted temperature.
  - **Exercise 3: Situação do aluno**
    - Read three grades entered by the user.
    - Calculate the student's average grade.
    - Determine the student's academic status based on the average.
    - Display the student's status.
  - **Exercie 4: Tabuada com laço**
    - Read the number entered by the user.
    - Calculates the multiplication results from 1 to 10.
    - Display the multiplication table.
  - **Exercise 5: Estatísticasde uma lista de notas**
    - Use a list containing the student's grades.
    - Calculate the highest and lowest grades.
    - Calculate the sum and average grades.
    - Display the calculated statistics.
  - **Exercise 6: Filtrar números pares**
    - Use a list containing numbers.
    - Separate the even and odd numbers into different lists.
    - Display the even and odd numbers.
  - **Exercise 7: Maior e menor venda da semana**
    - Use a dictionary containing the sales for each tday of the week.
    - Identify the day with the highest sales.
    - Indentify the day with the lowest sales.
    - Display the highest and lowest sales and their respective days.
  - **Exercise 8: Gerenciador de tarefas**
    - Create a list to store tasks.
    - Display a submenu with options to add, remove, search and display tasks.
    - Add new tasks to the list.
    - Remove tasks from the list.
    - Check whether a task is in the list.
    - Display all tasks in the list.
    - Allow the user to exit the submenu.

# Features

- Interactive menu system with input validation
- Separate classes for each exercise
- Use of `while` loops for menu and submenu navigation
- Use of `foreach` loops for iterating through collections
- Use of `List` and `Dictionary` for storing and manipulating data
