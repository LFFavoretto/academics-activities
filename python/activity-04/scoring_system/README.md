# Scoreboard System

A simple Python console application that manages a scoreboard of players, allowing score tracking, updates, and ranking visualization.

## Description

The program allows the user to:

- Add a new player with an initial score
- Add points to an existing player
- Check the score of a specific player
- Display all players and their scores
- Identify the player with the highest score
- Display a ranking sorted by score

## Features

- Dictionary-based data storage
- Input validation for numeric values
- Dynamic score updates
- Ranking sorted in descending order
- Player name normalization
