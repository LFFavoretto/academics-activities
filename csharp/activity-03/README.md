# Payment System

A simple C# console application that simulates a payment system with different payment methods, including cash, debit, and credit.

## Description

The application allows the user to:

- Make payments using different methods
- Apply a discount for credit card payments
- Store and list all completed payments

The system uses object-oriented programming concepts such as inheritance and polymorphism.

## Payment Methods

- Cash: Full payment amount is received
- Debit Card: Full payment amount is received
- Credit Card: Applies a 10% discount to the received amount

## Features

- Object-oriented design (base class and derived classes)
- Polymorphism for different payment behaviors
- Dynamic list of payments
- Console-based user interaction
