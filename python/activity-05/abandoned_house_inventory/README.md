# Abandoned House Inventory

A simple Python console application that records objects found in an abandoned house, including their location and danger level.

## Description

The program allows the user to:

- Register objects found in the house
- Store the room where each object was found
- Assign a danger level to each location
- Display all recorded objects with their details
- Count how many objects are considered high risk

The inventory has a limit of 3 objects.

## Features

- Dictionary-based data storage
- Input handling and formatting
- Object tracking by location and risk level
- Counting items based on a condition (high danger)
