# Resolut 3.0

A simple C# console application that provides two exercises:  
1. **Saldo do Vovô** – simulates deposits and withdrawals to track the lowest balance.  
2. **Blobs** – calculates how many days food lasts when consumed at half the amount each day.

## Description

The program:

- Displays a menu with three options:
  - **Exercise 1: Saldo do Vovô (code: 2434)**
    - Reads the number of days and initial balance.
    - For each day, asks the user to input a transaction (deposit or withdrawal).
    - Updates the balance and keeps track of the lowest balance during the period.
    - Displays the lowest balance at the end.
  - **Exercise 2: Blobs (code: 1170)**
    - Reads how many test cases the user wants to run.
    - For each test, asks for the amount of food.
    - Each day, the food amount is halved until it reaches 1 or less.
    - Displays the number of days the food lasted.

## Features

- Interactive menu system with input validation  
- Separate classes for each exercise  
- Use of loops (while) for repeated calculations  
- Console-based user interaction
