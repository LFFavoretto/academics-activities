# Longest Winning Streak

A simple Python program that reads a sequence of integers and finds the longest consecutive sequence of positive numbers.

## Description

The program:
- Asks the user how many numbers will be entered
- Stores the numbers in a list
- Identifies the longest sequence of consecutive positive numbers
- Calculates the sum of the values within that sequence

## Output

- Length of the longest sequence
- Sum of the values in that sequence
