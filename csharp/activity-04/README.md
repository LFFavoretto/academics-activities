# Number Frequency Counter

A simple C# console application that reads a list of integers and counts how many times each number appears.

## Description

The program:

- Asks the user how many numbers will be entered
- Reads integer values from the user
- Stores the values in a list
- Counts how many times each number appears
- Displays the frequency of each unique number

## Features

- Use of lists for data storage
- Nested loops for counting occurrences
- Avoids duplicate counting using a control list
