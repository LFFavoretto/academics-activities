# Prime Number Finder

A simple C# console application that calculates all prime numbers up to a user-defined limit and then prints all prime numbers within that range.

##  Description

The program:

- Asks the user to enter an integer between 1 and 200000
- Validates the input to ensure it is within the allowed range
- Uses a method to check if each number is prime
- Stores prime numbers in a list
- Displays all prime numbers up to the chosen limit

## Features

- Input validation for integers and range limits
- Prime number detection using divisor counting
- Iterative calculation of primes up to the given number
- List-based storage of prime numbers
- Console output of all results
